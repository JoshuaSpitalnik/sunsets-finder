# osint-data

Archive of public weather posts collected by `scripts/fetch-osint.mjs` (on `main`) for Sunset Finder's
"search past updates". One file per month in `archive/`, plus `archive/index.json`. Updated by the
"Deploy PWA to GitHub Pages" workflow every 30 minutes and published at `/osint-archive/`.
Telegram history was backfilled from 2025-01-01.
